# mobile_dash.github.io

Мониторинг прохождения опроса по методичке «Мобильные приложения СКС Ломбард»
(Telegram-бот `mobile-opros-bot`). Статический снимок: `index.html` генерируется скриптом
`build_static.py` из `storage/output/**/*.md` бота и коммитится сюда вручную/по cron —
сам файл не подключается ни к какой базе и не тянет данные извне.

Страница публична по прямой ссылке (`noindex, nofollow` — вне поиска), без справочника
сотрудников показывает только тех, кто уже прислал ответ.

Обновление снимка и вся логика сборки — в репозитории бота, `src/mobile_bot/monitoring/`.
